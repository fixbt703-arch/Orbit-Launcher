Orbit Launcher — публикация на GitHub без очистки личных данных

1. В репозиторий загружайте СОДЕРЖИМОЕ папки source.
2. Установщик release/OrbitLauncherInstaler.exe прикрепляйте к GitHub Releases.
   В source нет EXE. Отдельный OrbitLauncher.exe для публикации не нужен.
3. SHA256SUMS.txt содержит контрольную сумму установщика.
4. privacy-report.json содержит список файлов исходников и их контрольные суммы.

Установщик собран заново. Компилятор использует локальную конфигурацию служб
только для готового приложения. Файл AppConfiguration.Local.cs не копируется
в исходники; временная ссылка на него удаляется до проверки пакета.
Microsoft-вход и CurseForge настроены в приложении внутри установщика.
Перед упаковкой проверяются точные байты сборки внутри EXE и настоящий запрос
каталога CurseForge. Пользователям не нужно вводить свой API-ключ.
Ключ CurseForge не находится в открытых исходниках, но встроенный ключ
настольного приложения технически можно извлечь из бинарного файла.

Аккаунты, токены входа, настройки, игровые сборки, скины и миры из вашей
установки не копируются. Рабочая папка проекта и данные в AppData не очищаются.
Снимки экрана, игровые логи, тестовые миры и кэши сборки исключены.

Для пересборки лаунчера из source нужен .NET SDK 8 для Windows: build.bat.
Разработчик указывает собственные ключи в AppConfiguration.Local.cs по примеру
AppConfiguration.Local.cs.example. Этот файл исключён через .gitignore.
Для выпуска установщика нужны также Inno Setup 7 и доступ к API CurseForge.
Для изменения Orbit Client нужны Java 25 и локальная зависимость Skin Layers 3D;
см. source/OrbitClient/libs/README.md. Этот сторонний JAR не распространяется
в исходниках. Уже собранный Orbit Client входит в публичный EXE.

При повторном запуске tools\Build-GitHub.ps1 заменяется только прежний экспорт
со служебной меткой .orbit-github-export и только после успешной новой сборки.
Не храните собственные файлы в папке экспорта. Если сборка не удалась,
предыдущий экспорт сохраняется; путь к диагностике показывается в консоли.
cleaning.bat для публикации запускать НЕ НУЖНО.
