# Orbit Connect и «Запрет»: проверка 19.10.2026

Проверена установленная папка `C:\Users\Fixbt\Desktop\Zapret`, Flowseal 1.10.3,
все 22 стратегии `general*.bat`. Итоговые проверки входа/восстановления и внешнего
relay прошли на каждой стратегии, часть — после повторного прогона.
Устойчивый конфликт Orbit Connect с определённой стратегией не воспроизведён.

## Условия

- Game Filter выключен: `utils/game_filter.enabled` отсутствует.
- `ipset-all.txt` содержит только заглушку `203.0.113.113/32`; произвольные адреса
  игровых соединений не включены в IPSet.
- Запускался настоящий установленный `winws.exe` с аргументами каждого BAT.
  Подтверждены живой PID и сообщение `windivert initialized. capture is started.`
  Драйвер — `Desktop/Zapret/bin/WinDivert64.sys`.
- Стратегии запускались по одной; BAT-вызовы обновлений/служб/netsh не исполнялись.
  TCP timestamps уже были включены до проверки. Списки и настройки не менялись.
- SHA-256 winws: `AFFB4F69D2EA302A7ABCCD5325D81826E140DDAE014F1E070BC4A6C0DD555188`.

## Сценарии

Для каждой стратегии: два настоящих контроллера Orbit, собственный LAN-порт,
приглашение и Minecraft status через EasyTier; принудительная остановка только
своих основных core и проверка того же мира через Terracotta по прежнему локальному
адресу. Отдельно выполнялась 10-секундная зашифрованная передача случайных данных
через внешний `tcp://us01.225284.xyz:11010`, с проверкой целостности.

На `general.bat`, `general (FAKE TLS AUTO).bat` и `general (FAKE TLS AUTO ALT2).bat`
дополнительно запущены по два настоящих клиента Minecraft **26.2 / Fabric 0.19.5 /
Java 25**. Новый изолированный мир → открытие LAN → кликабельное приглашение в чате →
обычное прямое подключение → гость вошёл в мир. Клиенты завершены штатно; миры и
аккаунты пользователя не использованы. Малый измеренный RTT этих запусков относится
к двум клиентам на одном компьютере и не является обещанием интернет-пинга.

## Изменения и восстановление

Исправлен тестовый сервер и добавлена проверка фрагментированного запроса;
сетевая реализация Orbit Connect не менялась. Прежний `dist/OrbitLauncher.exe`
1.5.4.0 сохранён: SHA-256
`376EC459620D72CCF4108DB2277E5B732B9080AE8835654173BE584F1AF1ADB6`.

После проверки остановлены только созданные тестом процессы. Временная служба
драйвера WinDivert, отсутствовавшая до теста, остановлена и удалена; файлы самого
«Запрета» сохранены. Проверены исходные хеши 33 файлов настроек/стратегий/списков.

## Границы результата

Проверка относится к перечисленным стратегиям и **текущим** настройкам фильтров.
Game Filter с диапазоном всех игровых портов, IPSet `any`, изменённые списки,
другая версия winws, два физических компьютера за разными NAT/провайдерами и
многочасовая игра не проверены. Все версии Minecraft/загрузчиков этим тестом
не подтверждаются.

Источники устройства фильтров: [официальный README Flowseal](https://github.com/Flowseal/zapret-discord-youtube),
[документация WinDivert](https://reqrypt.org/windivert-doc.html).
Метод и собственные результаты выше основаны на локальных проверках.
