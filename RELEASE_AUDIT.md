# Проверка Orbit Launcher 1.4.6 — 17 октября 2026

Исправлены закреплённые зависимости Modrinth, дубликаты модов, выбор Java и точного
профиля NeoForge, обновление Microsoft-сессии и изоляция временных папок игровых
процессов. Установка модов готовит файлы до замены, сохраняет прежние JAR и
откатывает пакет при ошибке записи реестра. Необязательная загрузка не блокирует
основной мод. Изменения учтены в 11 новых регрессионных сценариях.

Вкладка «Скины» переработана для Microsoft и Ely.by: единая иерархия действий,
явное применение скина, раздельное удаление, понятные пустые состояния,
индикаторы выполнения и повтор после ошибки. Диалог добавления показывает
предпросмотр и проверяет поля внутри окна, сохраняя введённое. Локализованы
подписи и имена элементов доступности; перевод не меняет введённые пользователем
названия. Появились журналы запуска с маскированием токенов и доступом из меню
сборки. Убраны предупреждения nullable и неиспользуемое включение Windows Forms.

Проверки:

- Release-сборка лаунчера и тестового проекта: 0 предупреждений, 0 ошибок.
- Основной набор: 102 сценария, включая откат пакетной установки, неверный хеш,
  конфликт версий, отключённую зависимость, смену Java и независимые датапаки.
- Дополнительные WPF-сценарии: диалоги с асинхронными запросами, пагинация обоих
  каталогов, все основные страницы и окна, фокус, навигация и контраст.
- Вкладка «Скины»: оба провайдера, пустая и заполненная библиотека, успешное
  применение и ошибка сервиса на искусственных ответах, потеря индекса и повтор,
  предпросмотр PNG, длинные названия, RU/EN, клавиатура, высокая контрастность и
  увеличение содержимого до 125/150/200 процентов. Это проверка WPF-layout,
  а не переключение физических мониторов между значениями DPI.

Настоящие аккаунты и игровые миры для этих проверок не нужны. Реальный вход,
публикация скина на внешнем сервисе, полный игровой запуск и чистая установка
Windows требуют отдельной проверки. GitHub-публикация в эту работу не входит.

## Историческая проверка 1.2.1


Проверены операции со сборками и пользовательскими файлами, каталоги, загрузки,

## Найденные и исправленные ошибки

| Область | Ошибка и исправление |
| --- | --- |
| Сохранение JSON | Одновременные записи использовали один временный файл и могли завершаться ошибкой или терять изменения. Настройки, определения сборок, реестр установок и библиотека скинов используют общую атомарную запись с блокировкой по пути. Для списков применяется чтение и изменение под одной блокировкой. |
| Повреждённые определения | Повреждённый JSON мог скрыть сборки или сбросить список. Добавлено чтение резервной копии; повреждённые байты сохраняются отдельно для восстановления. Неудача переноса общих компонентов больше не скрывает исправную сборку. При непрочитанных определениях показывается предупреждение. |
| Экспорт ZIP | Старый архив удалялся до завершения нового экспорта; ошибка могла уничтожить резервную копию. Новый архив сначала полностью создаётся отдельно и только затем заменяет прежний. Экспорт внутрь самой сборки запрещён до записи файлов. |
| Создание, импорт, копирование | При ошибке оставались частичные сборки; параллельные операции конфликтовали по именам. Сборки готовятся во временной папке и становятся видимыми после успешного завершения. Копирование сохраняет пустые папки и не переносит резервные определения с прежним ID. |
| Перенос между компьютерами | Импорт сохранял чужой путь к Java и кешированный профиль загрузчика. Эти машинные значения сбрасываются, чтобы лаунчер заново выбрал компоненты. Проверена миграция русских имён физических папок в совместимые латинские имена с сохранением отображаемого названия и файлов. |
| Общие компоненты | Совпадение размера и времени файлов ошибочно считалось идентичностью. Теперь содержимое сравнивается по SHA-256; различающиеся файлы сохраняются. Архивирование и копирование отвергают ссылки на внешние папки. Удаление сборки проверяет принадлежность каталогу сборок. |
| Modrinth и CurseForge | Проверка хеша выполнялась после замены установленного файла. Теперь проверяется временная загрузка; при ошибке старый файл сохраняется. Временные имена уникальны, отмена проверяется до замены. Повторная установка той же карточки во время загрузки блокируется. |
| Компоненты Orbit Client | Одновременные установки конфликтовали по временным файлам. Установка сериализуется для каждой сборки, компоненты и отметка версии заменяются через отдельные временные файлы. Отключённые дополнительные моды сохраняют своё состояние. |
| NeoForge | Список версий отвергал Minecraft 26.x. Добавлены соответствия для новых номеров и патчей без смешивания соседних версий; сохранена поддержка 1.21.x. |
| Редактор сборок | Быстрый ввод версии, потеря фокуса или поздний сетевой ответ оставляли неподходящий загрузчик. Запросы отменяются и проверяются на актуальность, сохранение ждёт совместимой версии. Закрытые окна не обновляются из завершившихся запросов. Отключение Orbit Client во время запроса корректно возвращает доступ к полям. Переименование установленной сборки работает без сети. |
| Библиотека скинов | Один повреждённый PNG скрывал всю библиотеку; вариант SLIM мог строиться как classic. Ошибки изолированы по скину, вариант нормализуется до рендера. Параллельное удаление не возвращает старые записи; ошибка сохранения списка не удаляет сам PNG. |
| Запуск игры | Отмена не проверялась непосредственно перед запуском процесса, а мгновенное завершение процесса создавало гонку при чтении PID. Добавлены проверки отмены и безопасный порядок получения PID. |
| Метаданные и открытый код | EXE и установщик получали стандартную версию SDK вместо версии лаунчера. Версия задана в проекте и используется при запуске игры. Тест публичных исходников больше не падает из-за намеренно исключённого авторского JAR: только эта интеграционная проверка явно отмечается как пропущенная. |

## Проверки

- Основной набор: 58 сценариев с локальной зависимостью Skin Layers 3D;
  в публичном пакете — 57 сценариев и один явно отмеченный пропуск интеграции
  с защищённым авторским JAR.
- Пять сценариев реальных WPF-окон: ввод версии и потеря фокуса, устаревший ответ,
  переключение Orbit Client, редактирование без сети и закрытие окна с запросом.
- Пагинация Modrinth и CurseForge: по три страницы, 90 уникальных карточек,
  иконки, прокрутка и изменение размера окна на тестовых ответах.
- Рендер основных страниц и диалогов при нескольких размерах окна,
  стандартном и пользовательском фоне, проверка фокуса и состояний наведения.
- Сборка и запуск тестов из отдельной копии публичных исходников.
- Упаковка установщика, проверка встроенной конфигурации и реального запроса
  CurseForge API, проверка контрольной суммы установщика и состава исходников.

Тесты файловых операций используют собственные временные данные. Настоящие
миры, аккаунты и настройки пользователя не нужны для этих сценариев.

## Что этой проверкой не гарантируется

Не выполнялись вход в реальный Microsoft-аккаунт, полный запуск каждой комбинации
Minecraft/загрузчика/сторонних модов и установка на отдельный чистый компьютер.
Различающиеся общие файлы сохраняются, но конфликт сторонних профилей не
разрешается автоматически. Проверки уменьшают риск известных ошибок;
они не доказывают отсутствие всех возможных багов.

Исходники и установщик готовятся отдельно. Локальная конфигурация, аккаунты,
игровые данные и персональный скрипт публикации в исходники не включаются.
Сама проверка и сборка ничего не отправляют в GitHub.
